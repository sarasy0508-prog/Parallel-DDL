# Parallel-DDL

**把「死线前通宵赶工」变成「每天推进一点点」。**

Parallel-DDL 是一个个人 DDL 管理工具——你告诉它要做什么、什么时候截止，AI 帮你把大任务拆成一口一口能吃掉的小步骤，再安排到每天的早/中/晚时段里。不用再盯着一个庞大的 deadline 焦虑了。

## 谁适合用

主要面向学生群体：

- 本科生、硕士生、博士生
- 经常面对：作业、小组项目、小测、期中期末、论文、实验报告
- 总是拖到最后一刻才开始动手的人（没有在说我自己）

## 能做什么

### 任务看板

把所有任务以卡片形式排在一个看板上，一目了然。每张卡片里是 AI 拆好的步骤清单，做完一个勾一个，看着进度条往前走，很有成就感。

- 拖拽卡片调整优先级
- 步骤可以自由编辑、增删、重新排序
- 逾期任务自动变红提醒你

### AI 智能拆解

创建任务时选择「每步多长时间」（5分钟 / 10分钟 / 25分钟 / 45分钟），AI 会根据任务内容自动拆出合适粒度的步骤。拆完之后你有完全控制权——改名、增删、调整顺序都行。

### 日历安排

- 月视图看全局，哪天有 DDL 一清二楚
- 把步骤安排到具体某天的「早/中/晚」时段
- 每天打开看一眼，就知道今天该做什么

### 状态自动流转

| 状态 | 什么时候 |
|---|---|
| 草稿 | 刚创建，还没拆解 |
| 进行中 | 已拆解，正在做 |
| 已完成 | 所有步骤都勾完了 |
| 已逾期 | 过了 deadline 还没做完（卡片变红警告） |
| 已归档 | 做完了，手动归档，眼不见心不烦 |

## 使用方式

### 日常工作流

1. **创建任务** — 输入任务名称 + 截止时间 + 选择每步时长
2. **AI 拆解** — 点一下，等几秒，步骤自动生成
3. **调整步骤** — 觉得哪里不对就改，AI 不会比你更了解你的作业
4. **安排日程** — 把步骤拖到日历上，分配到每天的早/中/晚
5. **每天执行** — 打开看板，按计划勾选完成
6. **归档收工** — 全部做完，归档，开始下一个任务

### 安装启动

需要 Node.js 20+ 和 pnpm 9+：

```bash
pnpm install
cp apps/server/.env.example apps/server/.env
# 编辑 .env 填入你的 DeepSeek API Key
pnpm dev
```

打开浏览器访问 http://localhost:5173 就能用了。

## 设计理念

- **只做一件事** — 管理 DDL，不做日记、不做笔记、不做社交
- **单人使用** — 不需要登录，不需要注册，数据全部存在本地
- **AI 辅助而非 AI 主导** — AI 只负责拆解建议，最终决定权在你手里
- **不做提醒** — 不发邮件、不弹通知，你自己决定什么时候打开看

## 技术实现

这是一个 vibe coding 项目，前端 React + Vite，后端 Hono + 本地 JSON 文件存储，AI 用 DeepSeek API。Monorepo 结构，pnpm 管理。

详细技术文档见 [`docs/architecture.md`](docs/architecture.md)。
