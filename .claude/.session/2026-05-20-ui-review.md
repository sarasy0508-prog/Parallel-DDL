# UI 初稿 Review

- 日期:2026-05-20
- 文件:`demo-UI/gemini奶茶色.html`(Zen 极简风,奶茶色 #FAF9F5 + 浅米/灰)

## 总体评价

整体设计语言克制、留白讲究,中英混排 + Playfair 衬线斜体的"呼吸感"非常贴合"温柔拆解 DDL"的产品气质。**视觉基调不需要改**,以下问题主要是功能缺口与若干细节决策。

## A. 关键功能缺失(必改,无悬念)

| # | 缺失项 | PRD 依据 | 影响 |
| --- | --- | --- | --- |
| A1 | Form 缺"**单步时长**"选择(5/10/25/45 min 四档) | §3.2 | 没有此输入,AI 无法按颗粒度拆解 |
| A2 | 步骤上没有"**安排到日历**"按钮 | §2.6 / §4.3 | 唯一的关联入口缺失,日历无法工作 |
| A3 | 卡片没有"**+ 添加步骤**" / **删除步骤**图标 | §2.6 | 用户无法手动增删 |
| A4 | 卡片没有**任务级**编辑(改名/改 DDL)/ 删除 | §2.5 | 任务创建后不可调整 |
| A5 | Daily Slots 每槽位**只显示一个**步骤 | §4.3 "无上限" | 多步骤同时安排到同一槽位时显示不全 |
| A6 | 缺**已完成态**(归档按钮)、**已逾期态**(变红 + 警示 emoji)的视觉示例 | §2.4 | 关键状态没视觉规范 |
